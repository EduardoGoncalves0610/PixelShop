PIXELSHOP - Projeto Java

Estrutura:
src/
  com/pixelshop/
    App.java
    modelo/Produto.java
    testes/TesteCriacaoProduto.java
    testes/TesteEstoqueProduto.java

Como abrir no IntelliJ IDEA:
1. Extraia o ZIP.
2. Abra a pasta PixelShop no IntelliJ IDEA.
3. Marque a pasta "src" como Sources Root se o IntelliJ não fizer isso automaticamente.
4. Execute com.pixelshop.App para abrir o menu.
5. Os testes podem ser executados separadamente:
   - com.pixelshop.testes.TesteCriacaoProduto
   - com.pixelshop.testes.TesteEstoqueProduto

Compatibilidade:
Java 8 ou superior.
